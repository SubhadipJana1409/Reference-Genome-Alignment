# Reference Data

Reference files are **not committed to this repository** because they are large (50–80 MB)
and publicly available. Use one of the two options below.

---

## Option A — Real GRCh38 (recommended for real analysis)

Downloads the actual human chr22 from Ensembl and GENCODE v44 annotation.

```bash
bash scripts/download_data.sh
```

This will place the following files here:
- `data/reference/chr22.fa`
- `data/reference/gencode_v44_chr22_gtf`

---

## Option B — Synthetic benchmark chr22 (used in this project)

If you want to reproduce the exact benchmark results in this repo, generate the same
synthetic 5 Mb chr22 used here:

```bash
python scripts/simulate_reference.py
```

This creates `data/reference/chr22.fa` using `random.seed(42)` — deterministic and
GRCh38-coordinate-compatible.

For the GENCODE v44 chr22 GTF (real annotation, used for STAR index):

```bash
wget -O data/reference/gencode_v44_chr22_gtf.gz \
  https://ftp.ebi.ac.uk/pub/databases/gencode/Gencode_human/release_44/GRCh38.primary_assembly.genome.fa.gz

# Or extract chr22 from the full GTF:
wget -O /tmp/gencode.v44.annotation.gtf.gz \
  https://ftp.ebi.ac.uk/pub/databases/gencode/Gencode_human/release_44/gencode.v44.annotation.gtf.gz

zcat /tmp/gencode.v44.annotation.gtf.gz \
  | awk '$1=="chr22"' \
  | gzip > data/reference/gencode_v44_chr22_gtf.gz

gunzip data/reference/gencode_v44_chr22_gtf.gz
```

## After downloading

Once files are in place, run the full pipeline:

```bash
python scripts/alignment_benchmark.py --index-only   # Step 1: build indexes
python scripts/alignment_benchmark.py                 # Steps 1–5: full run
```
